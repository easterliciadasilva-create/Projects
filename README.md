## Project Overview

This repository contains several university machine learning projects exploring different modelling techniques and real-world datasets.

### Artificial Neural Network – Image Classification
Implemented a ResNet (Residual Network) to classify images correctly. Due to the large size of the dataset and the processing limitations of my laptop, the dataset had to be sampled before training. This may have influenced the model's overall accuracy and performance.

### Hotel Booking Data Analysis
The hotel booking dataset was explored across multiple notebooks, focusing on classification and regression tasks.

- **Classification:** Developed a model to predict whether a hotel booking would be cancelled.
- **Regression:** Analysed the relationship between different variables to identify which factors influence total revenue.

These projects demonstrate my experience with Python, machine learning, data preparation, classification, regression, model evaluation and data analysis.
